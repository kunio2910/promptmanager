# Prompt Manager

Website quản lý và tái sử dụng prompt AI theo cấu trúc.

## Chức năng

- Nhập và tạo prompt theo 8 nhóm: Subject, Clothing, Weapon/Prop, Environment, Camera, Lighting, Style và Quality.
- Xem trước prompt và JSON, sao chép hoặc xuất/nhập JSON.
- Lưu, tìm kiếm, chỉnh sửa, sao chép và xóa prompt trong thư viện.
- Quản lý tùy chọn và trường thông tin trong phần Cài đặt.

## Phát triển cục bộ

```bash
npm ci
npm run dev
```
